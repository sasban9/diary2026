YouTube Video Collector

Runs in your browser. Searches many queries, removes duplicates, sorts newest first and exports your list.

How to get a free API key (2 minutes)
  1. Open console.cloud.google.com and create a project.
  2. Go to APIs & Services, Library, search YouTube Data API v3, click Enable.
  3. Go to Credentials, Create credentials, API key. Paste it below.
Free quota is 10,000 units per day. Each search page costs 100 units (50 results), so roughly 100 pages a day. The key stays in your browser and is sent only to Google.
